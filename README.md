# ProPlatformu — Task Manager v1

Современная модульная платформа для совместного управления задачами, организациями и сотрудниками (воркерами).

---

## 🏗 Архитектура проекта

- **Backend API**: [Fastify](https://fastify.dev/) + [Prisma ORM](https://www.prisma.io/) + SQLite (нулевая конфигурация, работает прямо из коробки)
- **API Docs**: Swagger UI доступен по адресу [`http://localhost:3001/docs`](http://localhost:3001/docs)
- **Frontend Client**: React 19 + Vite + Tailwind CSS + Zustand + `@dnd-kit`
- **Аутентификация**: JWT (Bearer токен) + хеширование паролей bcryptjs

---

## 👥 Доменная модель (v1)

1. **Организация (`Organization`)**:
   - Рабочее пространство команды (например, "Pro Platform Team", "Fintech Solutions").
   - Управление участниками и их ролями (`OWNER`, `ADMIN`, `MEMBER`).
   - Переключение между организациями в один клик в хедере.

2. **Сотрудник / Воркер (`User` & `OrganizationMember`)**:
   - Профиль пользователя (имя, email, роль, аватар).
   - Назначение исполнителей на задачи из списка сотрудников текущей организации.
   - Фильтрация доски задач по конкретному воркеру или "Только мои задачи".

3. **Задача (`Task`)**:
   - Название, описание, срок выполнения (дедлайн).
   - Приоритет: **Низкий** (зеленый), **Средний** (желтый), **Высокий** (красный).
   - Статусы колонок: **Ожидает** (0) → **В работе** (1) → **Готово** (2) → **Отклонено** (3).
   - Интерактивный Drag & Drop перенос карточек между статусами с автосохранением на сервере.
   - Модальные окна создания и быстрого редактирования.

4. **Сообщения (`Message`)**:
   - Комментарии внутри карточки задачи (обсуждение конкретной задачи).
   - Общий чат команды внутри организации (`/chat`), не привязан к задаче.
   - Обновляются коротким поллингом, пока открыт соответствующий экран (без WebSocket в v1).

## 📁 Структура репозитория

```
client/   # React 19 + Vite + Tailwind клиент
api/      # Fastify + Prisma сервер
```

Корневой `package.json` содержит только общие скрипты (`install:all`, `run:all`, `dev:all`,
`build:all`, `dev`, `dev:api`, `build`, `build:api`, `db:seed`, `db:studio`), которые
проксируют вызовы в `client/` и `api/` через `--prefix`.

Для быстрой установки всех зависимостей (в корне, клиенте и сервере) одной командой:

```bash
npm run install:all
```

## 🚀 Быстрый запуск

### Запуск всего проекта (клиент + сервер одновременно):

```bash
npm run run:all
# или npm run dev:all
```

- Клиент откроется на: `http://localhost:5173`
- API сервер откроется на: `http://localhost:3001`
- Swagger документация: `http://localhost:3001/docs`

### Раздельный запуск:

```bash
# Запуск клиента Vite
npm run dev

# Запуск API сервера Fastify
npm run dev:api
```

### База данных и Prisma:

```bash
# Запуск начального сида данных (пользователи, организации, задачи)
npm run db:seed

# Открытие веб-интерфейса Prisma Studio для просмотра таблиц БД
npm run db:studio
```

## 📡 Основные эндпоинты API

- `POST /api/auth/register` — Регистрация нового пользователя и авто-создание организации
- `POST /api/auth/login` — Вход и получение JWT токена
- `GET /api/auth/me` — Данные текущего пользователя и его организаций
- `GET /api/organizations` — Список организаций пользователя
- `POST /api/organizations` — Создание новой организации
- `GET /api/organizations/:id/members` — Список сотрудников организации
- `POST /api/organizations/:id/members` — Добавление сотрудника в команду
- `DELETE /api/organizations/:id/members/:userId` — Удаление сотрудника из команды
- `GET /api/tasks?organizationId=1&assigneeId=2&status=1&search=test` — Задачи с фильтрацией
- `POST /api/tasks` — Создание новой задачи
- `PATCH /api/tasks/:id` — Обновление задачи (статус, исполнитель, приоритет и т.д.)
- `DELETE /api/tasks/:id` — Удаление задачи
- `GET /api/tasks/:id/messages` — Комментарии к задаче
- `POST /api/tasks/:id/messages` — Добавить комментарий к задаче
- `GET /api/organizations/:id/chat` — Общий чат команды (последние 200 сообщений)
- `POST /api/organizations/:id/chat` — Отправить сообщение в общий чат команды
- `DELETE /api/messages/:id` — Удалить сообщение (автор или OWNER/ADMIN организации)
